How identification works

The primary match comes from DirectShow CFactoryTemplate structures: class names, CLSID pointers, creation functions, initialization functions, and optional filter setup. Decoder and property-page classes are listed separately. Structural matches in unknown files remain candidates; GUIDs found only as bytes or text are clues. The page does not execute DllGetClassObject or verify runtime activation or video playback.
